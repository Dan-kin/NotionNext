## 纳入原则

一个来源只有同时满足以下条件才进入自动采集：

1. 与现有四个栏目直接相关；
2. 有稳定公开入口和可追溯原始 URL；
3. 采集成本、噪声和版权风险可控；
4. 不要求绕过登录、付费墙或访问限制；
5. 能明确判断它是“一手发布”还是“发现线索”。

`config/nd-content-sources.json` 是 V1 来源配置的代码源。`active: false` 表示已列入观察，但尚未进入定时采集。

## 停用条件

- 连续三次运行无法访问或页面结构失效；
- 候选长期重复、低相关或不可核验；
- 来源条款或访问策略不允许当前方式；
- 产生的人工审核成本持续高于内容价值。

停用只修改来源配置，不删除历史候选报告。
