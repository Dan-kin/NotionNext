# 栏目与筛选规则 V1

## 总定位

不是“巴黎活动大全”，而是面向中文艺术与文化人群的法国行动指南。每条内容至少回答一个问题：值得去吗、谁能申请、如何参与、与中法交流有什么关系。

## 栏目判断

1. 出现 `appel à projets`、`candidature`、`résidence`、`bourse`、`financement`、`prix`、`deadline` 等词，优先归入 **机会雷达**。
2. 明确涉及中国、华人艺术家、中法机构或双向文化合作，优先归入 **中法连接**。
3. 涉及艺术教育、职业身份、作品集、行业方法或法国制度解释，归入 **艺术路径**。
4. 其余有明确日期和地点的展览、演出及文化活动，归入 **本周去看**。

分类只是候选建议，人工可以调整。

## 评分（满分 12，最低 REVIEW 分数 6）

- 来源可靠性：1–3。官方机构最高；聚合发现入口最低。
- 可行动性：0–3。有日期/截止时间、地点、明确报名或参与动作。
- 受众相关性：0–3。艺术文化基本相关；职业机会或中文受众价值更高；明确中法连接最高。
- 时效性：0–2。未来仍可参与或近期新发布。
- 信息完整度：0–1。有清楚标题和摘要元数据。

分数只用于排序，不等于事实已经核实，也不直接触发发布。

## 去重

- 第一层：规范化 URL 完全相同。
- 第二层：规范化主题标题相同。
- 第三层：与现有网站 archive 的公开文章标题比对。

系统将疑似重复项标记或合并，但不自动删除任何 Notion 内容。

## 明确排除

- 只有宣传口号、没有可追溯信息的内容；
- 与法国艺术文化参与路径无直接关系的泛新闻；
- 纯商业软文、票务导流或无法区分广告与编辑内容的页面；
- 已结束且没有长期资料价值的活动；
- 需要猜测资格、费用、版权或主办方身份才能成立的内容；
- 与已有主题重复且没有实质变化的内容。

## 建稿建议

通过 REVIEW 后才人工建立 Notion `Draft`。V1 不改动现有 property mapping；继续使用 `status`、`category`、`date`、`slug`、`summary`、`tags`、`icon`、`password`。来源 URL 暂时写入正文末尾的“信息来源”，后续若要新增 `source_url` 等属性，必须另行评审和迁移。
