# 候选内容 REVIEW 清单

候选进入 Notion Draft 前，逐条检查：

- [ ] 原始链接可访问，标题和主办方身份一致。
- [ ] 如果来自 Offi、Slash Paris、On the Move 或 OpenAgenda，已打开主办方/场馆的一手页面。
- [ ] 日期、时间、地点、票价/免费条件仍有效。
- [ ] 征集类内容已核对资格、地区限制、语言、材料、费用、截止时间和结果通知方式。
- [ ] 没有把主办方宣传语写成已证实结果。
- [ ] 与现有文章不是重复主题；如为更新，已说明实质变化。
- [ ] 对中文读者有明确行动价值，而非简单翻译活动介绍。
- [ ] 摘要、图片和引用不侵犯来源版权；不复制来源全文。
- [ ] 已选择栏目，并映射到当前 `category` / `tags`。
- [ ] 新建状态为 `Draft`；只有 Dan 确认后才改为 `Published`。

## 停止条件

以下任一情况成立时，不建稿：

- 无法找到一手来源或主办方身份不明；
- 关键日期、资格或费用互相矛盾；
- 已过截止时间且没有长期解释价值；
- 需要新增法律、税务、签证或资质判断，但没有官方依据；
- 信息价值不足以覆盖核验和写作成本。
